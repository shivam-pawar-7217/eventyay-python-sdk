Installation
============

Requirements
------------
* Python 3.7 or higher.
* An Eventyay account and API Key (optional for public events).

Standard Installation
---------------------
You can install the Eventyay Python SDK directly from PyPI (once released) or via Git:

.. code-block:: bash

   pip install eventyay

Development Installation
------------------------
To install the SDK for development purposes:

.. code-block:: bash

   git clone https://github.com/shivam-pawar-7217/eventyay-python-sdk
   cd eventyay-python-sdk
   pip install -e .
