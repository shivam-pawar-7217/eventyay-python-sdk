Introduction
------------
The Eventyay Python SDK is a powerful and easy-to-use library for interacting with the Eventyay API. 
It supports both synchronous and asynchronous operations, complete with high-level abstractions for managing events, organizers, and more.

Key Features
------------
* **Full CRUD Support**: Manage organizers and events with simple methods.
* **Sync & Async**: Choice of ``EventyayClient`` or ``AsyncEventyayClient``.
* **Typed Models**: Pydantic-powered data validation and IDE autocompletion.
* **CLI Tool**: Manage your events directly from the terminal.
